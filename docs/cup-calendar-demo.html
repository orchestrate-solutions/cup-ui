Resource TimeGrid

Vertical time axis with one column per resource — Google Calendar / Family Chaos style.

click a slot or event to see callback output…
Show code
const cal = document.querySelector('#cal-rtg'); cal.setResources([ { id: 'alice', title: 'Alice' }, { id: 'bob', title: 'Bob' }, { id: 'carol', title: 'Carol' }, ]); cal.setOption('view', 'resourceTimeGrid'); cal.setOption('slotMinTime', '07:00'); cal.setOption('slotMaxTime', '19:00'); cal.setOption('slotDuration', '00:15:00'); cal.addEvent({ id: 'e1', title: 'Standup', resourceId: 'alice', startMins: 540, durationMins: 30, kind: 'event', }); cal.setOption('dateClick', (info) => { console.log('clicked', info.resourceId, 'at', info.mins, 'mins'); });

cup-calendar-event

Standalone event pill — kinds, tones, and states. Pills are self-aware: they broadcast their own identity and live spatial state during drag, and float in viewport space so they slide cleanly across column boundaries.

Pill event contract
<cup-calendar-event label="Standup" kind="event" tone="normal" state="ok" data-event-id="e1" data-start-mins="540" data-duration-mins="30" data-resource-id="alice" draggable></cup-calendar-event> // At pickup the pill announces itself with full identity + spatial state: el.addEventListener('cup-event-pickup', e => { // e.detail = { eventId, startMins, durationMins, resourceId, date, // pickupOffsetX, pickupOffsetY, pickupFracX, pickupFracY, // originRect: { left, top, width, height } } }); // During drag the pill emits its live rect (viewport coords, since the pill // is lifted to position:fixed so it can slide across column separators): el.addEventListener('cup-event-dragmove', e => { // e.detail = { eventId, clientX, clientY, pickupOffsetX, pickupOffsetY, // pickupFracX, pickupFracY, // originRect, currentRect, deltaX, deltaY } }); el.addEventListener('cup-event-dragend', e => { /* same shape as dragmove */ }); el.addEventListener('cup-event-resize', e => { /* { eventId, newHeightPx|newWidthPx, originSize } */ });
Default interactions

Every <cup-calendar> ships with a default hover tooltip and click modal — consistent across every view (resourceTimeGrid, resourceTimeline, timeGridDay/Week, monthGrid, timezones). Both layer on top of any user-supplied eventClick callback; they don't replace it.

Hover — wait ~300 ms over any event to see a tooltip card with title, start, end, and resource.
Click — opens a modal with full event details. Click outside or press Escape to dismiss.
Drag — pills float in viewport space (position:fixed) so they slide cleanly over column separators with a soft elevation shadow.
Opt-out / configure
// Default: both on, 300 ms hover delay cal.setOption('showTooltips', true); // false to disable cal.setOption('showEventModal', true); // false to disable cal.setOption('tooltipDelayMs', 300); // hover delay before tooltip appears // User callbacks still fire — they run alongside the default modal: cal.setOption('eventClick', info => { /* your custom logic */ });
Contact Card Tooltips

Wire resourceTooltip to transform every resource label hover into a rich contact card — name, avatar, role, department, local time, email, phone, and event load. Hover any person row below. The card positions itself to the right of the sticky label column.

Card preview — what hover shows
Show code
// Rich contact data on each resource const CONTACTS = [ { id: 'alice', title: 'Alice Chen', role: 'Product Designer', dept: 'Design', tz: 'America/Los_Angeles', email: 'alice@company.com', phone: '+1 415-555-0101', status: 'available', avatarColor: '#7c3aed' }, ... ]; cal.setResources(CONTACTS); // resourceTooltip: fn({ resource, resourceId }) → HTML string cal.setOption('resourceTooltip', ({ resource }) => { const initials = resource.title.split(' ').map(w => w[0]).join('').slice(0,2); const statusColors = { available: '#22c55e', busy: '#f59e0b', dnd: '#ef4444', offline: '#6b7280' }; const localTime = new Intl.DateTimeFormat('en', { timeZone: resource.tz, hour: 'numeric', minute: '2-digit', }).format(new Date()); return buildContactCard({ resource, initials, statusColors, localTime }); });
